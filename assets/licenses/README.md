# Runtime license sources

- [PyWinRT v3.2.1 license](https://github.com/pywinrt/pywinrt/blob/v3.2.1/LICENSE). Covers the runtime and generated Windows API projections. The installed wheels declare MIT but omit a license file.
- [Tcl 8.6.15 license](https://github.com/tcltk/tcl/blob/core-8-6-15/license.terms). Matches the Tcl version in the release build's Python installation.

These texts supplement the licenses collected from installed distributions, Python's LICENSE.txt and Tk's license.terms by `tools/generate_notices.py`.
